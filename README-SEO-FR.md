# Opti_Lewis — projet avec base SEO

## Fichiers
- `index.html` : contenu, titres, méta-description, URL canonique, Open Graph et données structurées `WebSite`.
- `css/style.css` : design et styles de la FAQ/contenu éditorial.
- `js/script.js` : filtres et produits de démonstration.
- `sitemap.xml` : sitemap XML pour la page d'accueil actuellement publiée.
- `robots.txt` : exemple de fichier robots à conserver pour référence ou à adapter en cas de domaine personnalisé.
- `assets/images/optilewis-social.png` : visuel de partage social Open Graph.

## URL actuelle
https://destymarketcontact-debug.github.io/Opti_Lewis/

## Publication sur GitHub Pages
1. Décompressez le ZIP.
2. Envoyez les fichiers et dossiers contenus dans `opti-lewis/` dans le dépôt GitHub correspondant, à la racine du dépôt (ou adaptez les chemins si vous choisissez un autre dossier).
3. Faites un commit et poussez les modifications.
4. Vérifiez que la page d'accueil, `sitemap.xml` et l'image sociale s'ouvrent sur le site publié.
5. Dans Google Search Console, ajoutez la propriété URL `https://destymarketcontact-debug.github.io/Opti_Lewis/` et soumettez `https://destymarketcontact-debug.github.io/Opti_Lewis/sitemap.xml`.
6. Utilisez l'inspection d'URL de Search Console pour demander l'indexation de la page d'accueil.

## Important à propos de robots.txt
Pour un site GitHub Pages de projet hébergé sous `/Opti_Lewis/`, le vrai fichier `robots.txt` reconnu à cette fin doit être à la racine de l'hôte (`https://destymarketcontact-debug.github.io/robots.txt`), qui n'est généralement pas contrôlable depuis le dépôt du projet. Le fichier `opti-lewis/robots.txt` inclus ici ne remplace donc pas le fichier racine de l'hôte. Si vous associez un domaine personnalisé, placez `robots.txt` à la racine de ce domaine et vérifiez l'URL publique.

## Avant d'utiliser le site commercialement
- Les prix et produits visibles dans la grille sont explicitement des exemples de démonstration. Remplacez-les par vos vrais produits et prix.
- Le formulaire de contact ne transmet pas de message. Connectez-le à un service de formulaire ou à un serveur avant de le présenter comme fonctionnel.
- Le panier et la commande ne réalisent aucun paiement.
- Remplacez les coordonnées fictives et les liens sociaux de démonstration par des coordonnées réelles ou retirez-les.
- Ne publiez pas de promesses de livraison, de garantie ou de qualité qui ne sont pas confirmées.
- Le contenu informatif ne remplace pas l'avis d'un professionnel de la vue.

## SEO : principes
- Une page doit cibler un sujet principal, avec un `title`, une description, un `h1` et du contenu utile cohérents.
- Ne mettez pas la longue liste de mots-clés dans une balise `meta keywords` : Google ne l'utilise pas pour le classement.
- N'ajoutez pas artificiellement des villes ou des mots-clés sans rapport avec vos services.
- Le sitemap aide à découvrir les URL, mais ne garantit pas leur indexation.
- Le balisage structuré décrit le site et ne garantit aucun résultat enrichi.
